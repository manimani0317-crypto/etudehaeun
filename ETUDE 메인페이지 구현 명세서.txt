# ETUDE 리디자인 메인페이지 구현 작업 지시서

## 프로젝트 개요
첨부한 Figma 디자인을 최대한 동일한 형태로 구현합니다. 단순히 화면만 비슷하게 만드는 것이 아니라 컴포넌트 구조, 반응형, 인터랙션, 접근성, 성능까지 고려하여 실제 서비스 수준으로 개발해주세요.

--

##규칙

- 절대 추정하지 말 것.
- Figma에서 확인되는 정보만 작성.
- 없는 기능은 "없음"이라고 작성.
- 확인 불가능한 값은 "확인 필요"라고 작성.
- 모든 Auto Layout, Grid, Component 구조를 분석.
- Spacing, Padding, Margin을 모두 기록.
- Typography(Font, Weight, Size, Line Height)를 기록.
- Color Token을 실제 값으로 기록.
- Radius, Shadow도 기록.
- Section별 Width, Height를 기록.
- Component 계층을 기록.
- Variant가 있다면 모두 기록.
- Hover / Pressed / Disabled 상태가 있다면 모두 기록.
- Prototype Interaction도 기록.
- Export Asset 위치도 기록.
- React 개발자가 그대로 구현 가능한 수준으로 작성.


---

# 개발 환경

- Next.js (App Router)
- TypeScript
- Tailwind CSS
- Framer Motion
- Swiper.js
- Lucide React Icons

---

# 구현 목표

- Figma 디자인과 최대한 동일한 레이아웃 구현
- 모든 UI는 재사용 가능한 컴포넌트로 제작
- Desktop First 방식
- 유지보수가 쉬운 구조
- 이미지 최적화 및 성능 고려
- Semantic HTML 사용

# 반응형 기준

- Desktop : 1920px
- Large : 1440px

- Tablet : 1024px
- Mobile : 768px 이하
- Small Mobile : 390px

콘텐츠 최대 너비는 1440px 기준으로 구현합니다.
