# ETUDE 메인페이지 — 순수 HTML / CSS / JS 버전

프레임워크 없이 동작하는 정적 버전입니다. 빌드 도구도, `npm install` 도 필요 없습니다.

## 실행

`index.html` 을 브라우저로 그냥 열면 됩니다. (더블클릭 또는 VS Code 에서 우클릭 → Open with Live Server)

## 파일 구성

```
static/
├── index.html          페이지 전체 마크업
├── css/
│   └── style.css       모든 스타일
├── js/
│   └── main.js         매장찾기 섹션 동작
└── images/main/        이미지 39개
```

### index.html

요소마다 `class` 가 하나씩만 붙어 있고, 그 이름은 Figma 레이어 이름(`data-name`)에서 가져왔습니다.

```html
<div class="event01" data-name="Event01"> ... </div>
```

`style.css` 에서 같은 이름(`.event01`)을 찾으면 그 요소의 스타일이 전부 들어 있습니다.

### css/style.css

세 부분으로 나뉘어 있습니다.

| 구역 | 내용 |
| --- | --- |
| 1. 기본 리셋 / 공통 변수 | 브라우저 기본 여백 제거 등. 보통 건드릴 일 없습니다. |
| 2. 요소별 스타일 | **여기를 주로 수정합니다.** 요소 하나당 규칙 하나. |
| 3. 인터랙션 | 호버 효과, 둥둥 뜨는 애니메이션 |

요소별 규칙은 서로 독립적이라, 하나를 고쳐도 다른 요소에 영향이 가지 않습니다.

### js/main.js

"Offline Etude"(매장찾기) 섹션의 동작만 들어 있습니다.

- 매장 목록 클릭 → 지도 이동, 핀 색상, 말풍선 변경
- 지도를 좌우로 드래그 → 이전/다음 매장으로 전환

매장 정보와 지도 위치는 파일 맨 위 `STORES` 배열에서 바꿀 수 있습니다.

```js
{
  name: '강남지상점',
  mapShift: 150,     // 지도를 가로로 미는 px
  mapShiftY: 170,    // 지도를 세로로 미는 px
  ...
}
```

## 알아두면 좋은 점

- **1920px 고정 폭 디자인**입니다. 반응형이 아니라서 창을 줄이면 가로 스크롤이 생깁니다.
- 웹폰트(Pretendard, Lisu Bosa, S-Core Dream, Noto Sans KR)는 CDN 에서 불러옵니다.
  **인터넷 연결이 없으면 폰트가 기본 글꼴로 나옵니다.**
- 상위 폴더의 Next.js 버전과는 별개입니다. 한쪽을 고쳐도 다른 쪽에 반영되지 않습니다.

## 원본과 동일한지 확인한 내용

Next.js 버전과 비교 검증을 마쳤습니다.

- `data-name` 이 붙은 294개 요소의 좌표·크기가 **픽셀 단위로 완전히 일치**
- 문서 높이 9926px 동일 (Figma 원본 캔버스와 같음)
- 이미지 50개 전부 정상 로드, 깨진 것 없음
- 웹폰트 4종 모두 로드
- 호버·애니메이션 규칙 26개 전부 대상 요소와 연결됨
- 콘솔 에러 없음
